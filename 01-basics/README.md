# Этап 1. Основы языка

Цель этапа: уверенно читать и писать простой Go-код и понимать, чем Go отличается от знакомых вам языков.

| Неделя | Содержание |
|---|---|
| [Неделя 1](week1/) | Инструменты, типы, управление потоком, функции, слайсы, map и строки, указатели: 7 пакетов с тестами |
| Неделя 2 | CLI `wordfreq`: топ-N слов из файла или stdin, с кириллицей |
| Недели 3–4 | 20–30 задач на [Exercism, трек Go](https://exercism.org/tracks/go), каждая с тестом |

## Этап пройден, когда

- [ ] все тесты в `01-basics/` зелёные, `gofmt` и `go vet` чистые;
- [ ] можете объяснить, почему `append` иногда меняет «чужой» слайс и как этого избежать;
- [ ] понимаете разницу между `len(s)` и числом символов в строке с кириллицей;
- [ ] знаете, когда передавать значение, а когда указатель;
- [ ] `wordfreq` работает на реальном тексте и покрыт тестами.
