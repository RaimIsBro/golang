# Изучение Go

Учебный репозиторий: путь от основ языка до высоконагруженных веб-сервисов в продакшене.
Один Go-модуль `github.com/RaimIsBro/golang`, папка на каждый этап плана.

| Папка | Этап | Статус |
|---|---|---|
| [`01-basics/`](01-basics/) | Основы языка | в работе |
| `03-concurrency/` | Конкурентность | впереди |
| `04-stdlib/` | Стандартная библиотека и инструменты | впереди |
| `05-web/` | HTTP и веб-сервисы | впереди |
| `06-db/` | Базы данных и очереди | впереди |
| `08-perf/` | Профилирование и оптимизация | впереди |
| `project/` | Сквозной проект: сокращатель ссылок, растёт с этапа 5 | впереди |

## Как работать с упражнениями

Каждое упражнение — пакет с готовыми тестами (`*_test.go`) и заготовкой решения,
где вместо тела функции стоит `// TODO: ваше решение`. Тесты не трогаем, пишем код, пока они не позеленеют.

```sh
go test ./01-basics/week1/day1/        # один пакет
go test -v -run TestGreet ./01-basics/week1/day1/   # один тест с подробным выводом
go test ./...                          # всё сразу
gofmt -w . && go vet ./...             # перед коммитом
```

CI на GitHub Actions проверяет форматирование, `go vet` и сборку. Тесты упражнений
тоже запускаются, но не роняют CI: сколько пакетов уже решено, видно в Summary запуска.
